# 原生 PDF 导出

在“文件 → 导出 PDF…”选择纸张、方向和页边距，点击“导出”后选择 PDF 保存路径。
没有默认快捷键。没有打开文档，或编辑器仍处于输入法组词/模式切换期间，导出入口不可用。

## 页面设置

- A4：210 × 297 mm。
- A5：148 × 210 mm。
- ISO B5：176 × 250 mm；此处不使用尺寸不同的 JIS B5。
- Letter：215.9 × 279.4 mm。
- 自定义：宽高均为 50–2000 mm；横向时交换宽高。
- 上、下、左、右边距分别设置，单位为 mm，不允许负数，正文横纵方向均须保留至少 20 mm。

默认 A4 纵向、四边 20 mm。每次打开设置窗口使用默认值。
正文使用捕获时的编辑器字体、字号及代码字体，以浅色背景输出，不跟随界面缩放。
本版不包含自定义页眉页脚或 PDF 后处理。

## 内容和文件保护

打开设置窗口时先同步编辑器内容，再捕获正文、文档名称、图片基准目录和字体设置。
支持导出未保存的编辑；切换标签或外部打开其他文件不会更换已经捕获的文档。
导出不会修改 Markdown 文件、保存基线、脏状态、编辑器实例或撤销历史。

相对图片以源 Markdown 所在目录解析，通过现有图片授权入口逐文件加载。
含中文、空格、`#`、`%` 的文件名仍按原路径处理。未保存文档没有相对路径基准，
此类图片无法解析时会报错；可改用绝对路径或先保存 Markdown。

公式、代码高亮、图表、字体和图片准备完成后才开始打印。资源加载失败、超时或图表
渲染失败时保留设置窗口并显示错误，不将缺图输出报告为成功。网络图片及 PlantUML
等远程资源仍需要网络访问；正文不会上传给 PDF 转换服务。

原生引擎先生成私有临时目录中的 PDF，成功后通过现有原子写入入口保存最终文件。
失败时不替换目标文件，结束后销毁导出 WebView 并清理临时文件。PDF 不能覆盖其源文档。
目标文件在渲染期间被外部修改、新建或更换符号链接时，写入会停止，需重新选择目标。
准备或打印期间按钮暂时禁用；页面准备和原生打印都有超时保护。

## 实现结构

- `PdfExportDialog.vue`：页面设置、参数校验和结果反馈。
- `src/export/`：参数契约、HTML 整理和独立导出页面。
- `src/platform/tauri/pdfExport.ts`：系统保存对话框及 IPC 适配。
- `src-tauri/src/pdf_export/`：任务所有权、临时文件及各平台打印接口。

`pdf-export.html` 是独立构建入口，仅在导出时创建隐藏 WebView，不加载应用主界面或
新建 Muya 实例。复用 MarkdownToHtml 渲染器，导出窗口具有独立的图表配置及 DOM；
KaTeX 定位样式、纯 SVG 图表、代码样式和字体保留在打印页面中。
原生页面设置统一管理纸张与边距，正文不再额外叠加 CSS 页边距或编辑器 padding。

平台后端：

- Linux：WebKitGTK `PrintOperation` + GTK 的 PDF 文件输出后端。横向转换为实际纸张
  宽高，避免 GTK/WebKit 旋转路径使非对称边距的布局和绘制比例不一致。
- Windows：WebView2 `PrintToPdf`，启用背景，禁用引擎默认页眉页脚。
- macOS：WKWebView 的 `printOperationWithPrintInfo`，使用 `NSPrintInfo` 的 PDF 保存任务；
  该接口要求 macOS 11 及以上，旧版本会明确报告不支持。

原生绑定复用当前 Tauri/Wry 锁定版本，未新增浏览器或排版器运行时。升级 Tauri 的
原生绑定版本时需要同步检查这些接口。

## 验证范围

Linux 自动化使用独立 Xvfb 和 D-Bus 会话中的完整 Tauri 程序，通过真实菜单和系统
保存对话框导出。覆盖 A4 纵向、ISO B5 横向、自定义纸张、非对称四边边距，多页正文、
中英文、KaTeX、Mermaid、代码块、本地 SVG 图片及原 Markdown 文件不变。
Poppler 检查实际 PDF 页面尺寸、文字边界和末尾内容，并生成页面图片供视觉检查。
部分系统中文字体的 PDF 字符映射含兼容部首，文字提取比较使用 Unicode NFKC 归一化。

Windows/macOS 后端源码已使用相应 Rust target 和真实原生绑定完成独立类型检查，
但完整程序和实际输出尚需在相应系统中编译、运行验收；类型检查不代替平台验收。
各平台字体和打印引擎仍可能影响换行、页数及复杂表格的分页。

测试入口见 [测试说明](../tests/README.md#原生-pdf-导出回归)。
