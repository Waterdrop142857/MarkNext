# HTML 导出

选择“文件 → 导出 HTML…”，点击“导出”并选择 `.html` 或 `.htm` 保存路径。
没有默认快捷键，也无需安装额外转换工具。

导出的是打开浮窗时的内容快照，包含未保存的编辑。之后切换标签或外部打开其他文件，
不会改变本次导出的内容。导出不会保存 Markdown、重建编辑器或改变撤销历史。

输出是可用普通浏览器独立打开的单个 HTML 文件，包含：

- Markdown 排版、表格、链接和代码语法高亮。
- 内嵌样式、KaTeX 公式及其字体。
- 静态 SVG 图表，无需在接收方运行 Mermaid 等 JavaScript。
- 内嵌本地图片；图片相对路径以源 Markdown 所在目录为基准，支持中文和特殊字符文件名。
- 捕获时的正文、代码字体设置和正文字号；接收设备缺少指定字体时使用字体回退。

远程图片保留原网址，打开导出文件时仍需网络访问；依赖远程服务的图表在导出时也需联网。
未保存文档没有相对图片路径的基准目录，可先保存 Markdown 或使用绝对图片路径。
本地图片以 data URI 内嵌，文件体积会随图片大小增加。图片、字体或图表准备失败会报告错误，
不会将缺少资源的文件视为导出成功。

用户 HTML 沿用净化流程，移除脚本、事件属性及会影响整个页面的样式和导航设置。
输出不含导出工作窗口的脚本或 Tauri 调用，并包含限制脚本和表单的 CSP。

PDF 与 HTML 共用 `document-export.html`、`src/export/renderDocument.ts` 和
`src-tauri/src/document_export/`：前端生成文档，PDF 交由原生打印后端分页，HTML 则序列化
生成的文档。两者均在独立隐藏 WebView 中渲染，复用文件身份检查及原子写入保护。
输出不会覆盖源文档；目标在渲染期间被外部修改或新建时停止写入。

当前已在 Linux 完整 Tauri 程序中验证实际保存，并将生成文件断网独立打开，检查全部 20 个
公式字体、图片、图表及代码高亮。Windows/macOS 后端调整通过目标平台类型检查，仍需实机验收。

测试入口见 [测试说明](../tests/README.md#html-导出回归)。
