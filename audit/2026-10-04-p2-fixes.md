# P2 修复与窗口滚动边界

对应原始审计第 4–8 项；第 9 项测试基础设施已在 P1 阶段修复。本次也处理用户补充的小窗口全局滚动问题。

| 问题 | 实现与验收行为 |
| --- | --- |
| 空查询/文件切换使用旧匹配 | 空查询清理匹配并禁用替换；F3/替换使用当前查询，文件/模式/编辑器变化重建搜索，关闭文档清除旧编辑器上下文。内容变更后刷新匹配偏移，保存查找选项。 |
| 源码替换无关选区 | 单次替换接受查询，选区必须等于一个真实匹配才可修改；有效替换定位下一处，包含查询词的替换文本不会使命令卡在刚替换的位置。 |
| 模式切换丢源码撤销 | CodeMirror 按文档 generation 懒创建、保持同一实例；WYSIWYG 内容变化重置旧源码历史，文档切换不继承历史。保留原有 Muya 会话撤销边界。 |
| 缺少本地图片上下文 | 显式文档路径解析，支持 POSIX/Windows/UNC、上级目录和编码字符；行内、引用、HTML 图片统一接入 Tauri asset URL，先授权单文件再请求。Space/修饰键预览及拖拽/替换工具同样接入解析接口。另存为更新目录，无路径文档不猜测相对目录。 |
| 异步图表结果覆盖 | 渲染版本、独立连接目标和提交检查共同隔离旧成功/失败；清空、移除与销毁使旧请求失效，晚到绘制只触碰旧容器。复用相同请求，清理 observer、点击订阅与 Vega view。 |
| 窗口整体被滚动 | 根文档和外壳固定到窗口尺寸，标题栏/状态栏不收缩，长状态文本截断；长内容只在 Muya/CodeMirror 内部滚动。 |

没有新增 pnpm 包。Tauri 开启内置 protocol-asset feature，Cargo.lock 包含其 crates.io 依赖 http-range 0.1.5；资源 scope 初始为空，不授权整个目录或全局通配符。前端传入具体图片后，原生验证目标存在、是文件且有支持的图片扩展名，再授权原始路径与规范化目标。

正式回归位于 src 下和 `tests/e2e/p2.spec.ts`，历史审计输入也已反转为正确行为断言。统一入口、报告和手动指南见 [测试指南](../tests/README.md)。
